# Respondo

Production-oriented Finnish B2B SaaS for website customer service. The public site, signup, Stripe subscription flow, account login, customer workspace, approved knowledge base, OpenAI-backed chat, embeddable widget, conversation history, billing portal, cancellation-at-period-end flow and legal/privacy pages are included.
